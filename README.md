# マジック・ブロック

普通の学校と魔法学校、2つの姿を持つ生徒たちと相棒（ライオン／アナグマ／ワシ／ヘビ）で遊ぶ、スマホ向けの陣取りボードゲーム（2〜4人オンライン対戦＋CPU戦）。

通常モードと魔法使いモード（魔法カードでルールが変わるモード）を切り替えて遊べます。

※本作品は非公式のファンメイド作品です。原作『ブロックス』（Mattel）および『ブロックスシャッフル ポケモンエディション』のルールを参考にし、名称・デザインは独自のものに置き換えています。
